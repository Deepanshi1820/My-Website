# My Own Website
Build this website with four webpages (homepage, quiz, articles and contact)
Constraint: Use only HTML

## Not so commonly used Tags:
+ Color Picker: you can set the color from the color palette
+ Accordion: view/hide details
+ Progress Bar: no need to use JS to show progress, use HTML instead
+ Autocomplete: shows list of objects you can choose from
+ Iframe Tag: webpage within webpage

Lot of stuff has been depricated from HTML5 for the sake of CSS styling,
but it's pretty good building and figuring out purely using HTML5.
